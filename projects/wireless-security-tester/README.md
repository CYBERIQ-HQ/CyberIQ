# Wireless Security Tester

<div dir="rtl">

**أداة اختبار أمن لاسلكي للاستخدام المختبري**، مبنية على متحكم **ESP32**، تُستخدم ضمن مختبرات الأمن السيبراني لتقييم مدى مقاومة الشبكات والأجهزة اللاسلكية للتهديدات، في بيئة معزولة ومصرّح بها.

> **إشعار استخدام:** هذه الأداة مخصصة حصراً للتدريب واختبار الأنظمة التي يملك المستخدم تصريحاً صريحاً باختبارها، ضمن بيئة مختبرية معزولة. استخدامها على شبكات أو أجهزة دون إذن غير قانوني ويخالف أخلاقيات الأمن السيبراني. وُثّقت هنا على مستوى عام فقط ودون تفاصيل تشغيلية.

## الغرض (تعليمي ودفاعي)

- قياس مدى تأثّر أجهزة Wi-Fi و Bluetooth بالتهديدات اللاسلكية ضمن المختبر.
- محاكاة سيناريوهات أمنية لتدريب الطلبة على **الكشف عن هذه التهديدات والدفاع ضدها**.
- دعم تطوير وتقييم المشاريع الدفاعية في الفريق (مثل Cyber Shield و Evil Twin Detector).

## المميزات العامة

- صغير الحجم ومحمول، يعمل بالبطارية.
- مبني على ESP32 قابل للبرمجة والتحديث.
- منخفض الكلفة، ومكوّناته متوفرة محلياً.

## الحالة

نموذج أولي للاستخدام المختبري الداخلي. يُستخدم كأداة مرافقة لتطوير المشاريع الدفاعية وتقييمها.

| | |
|---|---|
| **المنصة** | ESP32 |
| **المجال** | اختبار أمن لاسلكي مختبري (تعليمي) |
| **الحالة** | نموذج أولي — استخدام مختبري مصرّح به فقط |

**EN:** *Wireless Security Tester* — an ESP32-based lab tool for evaluating the resilience of Wi-Fi/Bluetooth devices in an **isolated, authorised lab environment**, used to train students to detect and defend against wireless threats. Documented at a high level only. Unauthorised use is illegal and against cybersecurity ethics.
