# Evil Twin Detector

<div dir="rtl">

**كاشف التوأم الخبيث** — مراقب أمني ذكي لشبكات Wi-Fi مبني على **Raspberry Pi Pico W**، يكشف نقاط الوصول المزيفة (Evil Twin / Rogue AP) في الوقت الحقيقي.

التوأم الخبيث نقطة وصول احتيالية تقلّد شبكة شرعية باستخدام نفس اسم الشبكة (SSID) لخداع المستخدمين، وتُستخدم في هجمات اعتراض البيانات (Man-in-the-Middle). يرصد هذا الجهاز وجودها وينبّه عليها.

## الأهداف

- الكشف المبكر عن نقاط الوصول المزيفة في الوقت الحقيقي.
- حماية المستخدمين من هجمات اعتراض البيانات وتقليل سرقة البيانات الحساسة.
- رفع الوعي الأمني في الشبكات المحلية بحل منخفض التكلفة.

## كيف يعمل (مبدأ عام)

يمسح الجهاز الشبكات المحيطة ويجمع خصائصها (SSID، عنوان MAC/BSSID، قوة الإشارة، القناة، نوع التشفير)، ثم يقارنها بالشبكة الموثوقة المحفوظة؛ فإذا وجد شبكة تحمل الاسم نفسه بعنوان مختلف يعتبرها مشبوهة وينبّه عليها.

## المميزات

- مراقبة مستمرة وتنبيه فوري عند اكتشاف شبكة مقلّدة.
- شاشة عرض مباشرة (LCD/OLED) للتحذيرات.
- استهلاك طاقة منخفض، قابل للحمل، ويعمل بدون إنترنت (Offline Detection).
- كلفة تصنيع منخفضة.

## الجهات المستفيدة

الجهات الحكومية والجامعات، والقطاع الخاص (بنوك، فنادق، مقاهٍ توفّر Wi-Fi)، والمؤسسات الصغيرة والمتوسطة.

## الحالة والتطوير

نموذج أولي. مسار التطوير يشمل خوارزميات تحليل إشارة لتقليل الإنذارات الكاذبة، تنبيهات صوتية/عبر الهاتف، تطبيق موبايل، ولوحة مراقبة سحابية.

**EN:** *Evil Twin Detector* — a Raspberry Pi Pico W based Wi-Fi security monitor that detects rogue/evil-twin access points in real time by comparing nearby networks against a trusted SSID/BSSID baseline. Portable, offline-capable, low-cost. Defensive use only.
