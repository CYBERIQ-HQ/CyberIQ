# TV Box HomeSOC

<div dir="rtl">

**مركز عمليات أمنية مصغّر** يحوّل جهاز **Android TV Box** إلى خادم أمني يعمل بنظام **Linux**، لمراقبة الشبكة وإدارتها وتحليل الأحداث الأمنية داخل الشبكات الصغيرة والمتوسطة.

يُربط الجهاز بالشبكة عبر Managed Gigabit Switch، فيراقب الأجهزة المتصلة، ويدير DNS، ويحجب الإعلانات والاتصالات المشبوهة، ويعرض كل ذلك في لوحة تحكم واحدة.

## الأهداف

1. إنشاء مركز أمني مصغّر منخفض التكلفة لمراقبة الشبكة.
2. مراقبة الأجهزة المتصلة واكتشاف غير المعروف منها.
3. طبقة حماية إضافية من المواقع والنطاقات الضارة عبر DNS.
4. اكتشاف الأنشطة والهجمات الشبكية المشبوهة.
5. تسجيل الأحداث الأمنية للتحليل، مع نظام تنبيهات فورية.

## المكونات البرمجية (المنظومة)

| المكوّن | الوظيفة |
|---|---|
| Linux / Armbian / Debian | نظام التشغيل |
| Docker | تشغيل الخدمات وعزلها |
| AdGuard Home | تصفية DNS وحجب الإعلانات |
| Suricata | IDS/IPS |
| Firewall | التحكم بالاتصالات |
| WireGuard / Tailscale | VPN |
| Web Dashboard | واجهة الإدارة والمراقبة |
| Telegram Bot | التنبيهات |
| Threat Intelligence / Forensics | تحليل المؤشرات والحوادث |

## المميزات

- حماية: جدار ناري، أمن DNS، حجب المواقع والنطاقات الخبيثة، IDS/IPS.
- مراقبة شبكة: اكتشاف الأجهزة (IP/MAC/Hostname)، ومراقبة الاتصالات والاستهلاك.
- تحليل جنائي: حفظ السجلات، الجدول الزمني للأحداث، تاريخ الأجهزة، التحقيق في الحوادث.
- تنبيهات: جهاز جديد، نشاط مشبوه، مسح منافذ، حركة برمجيات خبيثة.

## الجهات المستفيدة

الدوائر الحكومية (كنموذج SOC/DFIR منخفض الكلفة)، الجامعات (مختبر تدريبي)، والمؤسسات الصغيرة والمتوسطة.

## الحالة والتطوير

نموذج أولي عامل. مسار التطوير يشمل: VLAN وPort Mirroring، أدوات مثل Zeek و Wazuh (SIEM) و MISP و TheHive و Grafana، وتحليل السلوك واكتشاف الشذوذ، ودمج الذكاء الاصطناعي لتحليل التنبيهات.
