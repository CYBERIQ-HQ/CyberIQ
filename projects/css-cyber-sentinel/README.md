# CSS — Cyber Sentinel System

<div dir="rtl">

**مختبر أمن سيبراني صغير ومحمول** مبني على **Raspberry Pi 5** يعمل بنظام **Kali Linux**، يتحوّل إلى أداة لمراقبة وتحليل الشبكات واكتشاف المشاكل الأمنية فيها بشكل قانوني.

يعمل الجهاز كـ"مراقب أمني للشبكة": يكتشف الأجهزة المتصلة، ويحلّل حركة البيانات، ويفحص نقاط الضعف، ويعرض تقريراً بحالة الأمان.

## الأهداف

- **تعليمية:** تدريب المستخدم على أساسيات الأمن السيبراني وأدوات Kali Linux (مثل Nmap و Wireshark) بشكل عملي.
- **أمنية:** مراقبة الشبكات واكتشاف الأجهزة غير المصرّح بها وكشف نقاط الضعف قبل استغلالها.
- **تقنية:** تحويل Raspberry Pi إلى منصة أمن سيبراني متكاملة بواجهة بسيطة ونظام تقارير تلقائي.

## المميزات

- صغير الحجم ومحمول — يعمل كمختبر أمن متنقل.
- منخفض الكلفة مقارنة بأجهزة الأمن السيبراني الاحترافية.
- يعتمد على بيئة Kali Linux الغنية بأدوات الأمن.
- تحليل في الوقت الحقيقي مع نظام تقارير مفهوم.
- قابل للتطوير (إضافة شاشة وواجهة رسومية، ودمج الذكاء الاصطناعي مستقبلاً).

## الجهات المستفيدة

الجامعات والمختبرات التعليمية، مراكز الأمن السيبراني، وأقسام تقنية المعلومات في المؤسسات.

## الحالة والتطوير

نموذج أولي عامل. مسار التطوير المستقبلي يشمل دمج الذكاء الاصطناعي لتحليل التهديدات وتحويله إلى منصة تدريب متقدمة (Cyber Lab).
