# TSS — Tactical SIGINT Suite

<div dir="rtl">

**منظومة استطلاع إلكتروني محمولة** (حقيبة تكتيكية متكاملة) تعتمد على **الراديو المعرّف برمجياً (SDR)** والذكاء الاصطناعي، لتحليل الطيف الترددي وكشف التهديدات اللاسلكية وتحديد اتجاه ومصدر الإشارة.

صُمّمت لتكون محمولة، سريعة الانتشار، منخفضة الكلفة مقارنة بالأنظمة العسكرية الثقيلة، وقابلة للتطوير والتحديث.

## الأهداف

1. تعزيز الوعي الإلكتروني الميداني بفهم النشاط اللاسلكي المحيط بشكل فوري.
2. كشف التهديدات اللاسلكية (أجهزة التشويش، الطائرات المسيّرة، البث غير الشرعي).
3. تحديد مصادر الإشارات واتجاهها وموقعها التقريبي ومستوى خطورتها.
4. توفير منصة محلية قابلة للتطوير تقلّل الاعتماد على الأنظمة الأجنبية مرتفعة الكلفة.
5. دعم الأمن السيبراني الميداني.

## المكونات (عام)

| الفئة | أمثلة |
|---|---|
| البرمجيات | أطر SDR مثل GNU Radio، ذكاء اصطناعي طرفي (TensorFlow Lite / ONNX)، خرائط وتتبّع GPS/GIS |
| العتاد | وحدات SDR، وحدة معالجة (مثل NVIDIA Jetson / Raspberry Pi / Intel NUC) |
| الهوائيات | متعددة الاتجاه واتجاهية (Yagi / Helical) |
| الطاقة | بطاريات ليثيوم مع إدارة طاقة ذكية |

## المميزات

- تغطية ترددية واسعة وتحليل طيف.
- تحليل إشارة مدعوم بالذكاء الاصطناعي الطرفي (Edge AI) وتحديد الاتجاه (Direction Finding).
- حماية المنشآت الحيوية والقوافل والشخصيات، وكشف التشويش قبل حدوث التأثير.

## الجهات المستفيدة

الأجهزة الأمنية والعسكرية، وحماية البنية التحتية والمنشآت الحيوية.

## الحالة

قيد التطوير — منصة متقدمة تجمع الذكاء الاصطناعي وتحليل الإشارات وتحديد المواقع ومراقبة الطيف الترددي.

| | |
|---|---|
| **المنصة** | SDR + حوسبة طرفية + ذكاء اصطناعي |
| **المجال** | استطلاع · تحليل طيف ترددي · حماية ترددية |
| **الحالة** | قيد التطوير |

**EN:** *Tactical SIGINT Suite* — a portable electronic-reconnaissance platform based on SDR and edge AI for RF spectrum analysis, wireless-threat detection, direction finding and signal-source localisation. Designed to be portable, rapidly deployable and lower-cost than heavy military systems. Intended for authorised security/defence use.
