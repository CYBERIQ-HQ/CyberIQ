# Cyber Shield — ESP32 Defense System

<div dir="rtl">

**نظام مدمج لمراقبة الأمن اللاسلكي** مبني على متحكم **ESP32-WROOM-32**، يعمل كعقدة دفاعية مستقلة تمسح نطاق 2.4 غيغاهرتز، وتصنّف التهديدات، وتنبّه عليها في الوقت الحقيقي.

يعمل في وضع مزدوج (AP+STA): يستضيف نقطة وصول خاصة بلوحة تحكم عبر المتصفّح تعرض الشبكات المكتشفة وعدادات الأحداث وتحليل الإشارة وسجل الأحداث، مع تنبيه صوتي عبر صافرة.

## الأهداف

- رفع مستوى الأمن اللاسلكي عبر مراقبة شبكات Wi-Fi باستمرار.
- الكشف والتنبيه المبكر عن التهديدات (محاولات التشويش، الشبكات المزيفة، النشاط غير الطبيعي).
- حل منخفض التكلفة وسهل الاستخدام مقارنة بالأنظمة التقليدية، مناسب للمنازل والشركات الصغيرة.

## ما يكتشفه

- محاولات فصل الأجهزة عن نقاط الوصول (Deauthentication).
- أنماط حركة مرور غير طبيعية (إغراق / فيضان الطلبات).
- مؤشرات التشويش الراديوي.
- الشبكات المخفية ونقاط الوصول المارقة (Rogue AP) والتوأم الخبيث (Evil Twin).

## المميزات

- نظام مستقل مدمج لا يحتاج خادماً خارجياً.
- مراقبة فورية مع تصنيف التهديدات حسب النوع ومستوى الإشارة.
- تنبيهات صوتية مميزة لكل نوع تهديد + لوحة تحكم عبر الويب.
- استهلاك طاقة منخفض، يعمل 24/7، وسهل النقل والتركيب.

## الحالة والتطوير

**نموذج أولي متقدم** — جهاز فعلي يعمل على ESP32 مع لوحة تحكم جاهزة، وتنبيهات صوتية، وكشف شبكات وعدادات أحداث في الزمن الحقيقي.

مسار التطوير يشمل: الانتقال إلى ESP32-S3 وشاشة لمس وتخزين microSD، إضافة حساسات، دمج الذكاء الاصطناعي لتعلّم السلوك الطبيعي للشبكة، تطبيق موبايل، وتعزيز حماية الجهاز نفسه.

**EN:** *Cyber Shield* — a standalone ESP32-based wireless monitoring node. Scans the 2.4 GHz band, classifies threats (deauth, flooding, jamming indicators, rogue/evil-twin APs) and alerts in real time via a buzzer and a web dashboard. Low-cost, defensive, 24/7.

> نظام دفاعي للكشف والمراقبة، للاستخدام ضمن بيئات مصرّح بها.
